# 京都大学書道部 公式サイト 運用マニュアル

サイト（https://kushodo.club）の中身を更新する人向けの説明です。
プログラミングの知識は要りません。ブラウザで microCMS の管理画面を開いて、文字を入力して「公開」を押すだけです。

---

## 1. はじめに

### 管理画面に入る

1. https://kushodo.microcms.io を開く
2. **京大書道部の Google アカウント**でログインする

### 更新できるもの

| 管理画面のメニュー | サイトのどこに出るか |
| --- | --- |
| お知らせ | トップの「お知らせ」、お知らせ一覧、記事のページ |
| 書展 | トップの「前回／次回の書展」、作品紹介の「書展」、書展のページ、パンフレット |
| パフォーマンス | 作品紹介の「書道パフォーマンス」 |
| サイト設定 | トップの写真と紹介文、書道部についての練習日・部室・入部案内・連絡先、ヘッダーの X・Instagram |

これ以外（ページのデザイン、書道部についての長い文章など）を変えたいときは、開発担当に相談してください。

### 公開のしくみ

- 「**公開**」を押すと、数分（だいたい3〜5分）でサイトに反映されます。すぐには変わりません。
- 「**下書き保存**」はサイトに出ません。書きかけのときはこちら。
- 10分以上待っても変わらないときは「8. 困ったとき」を見てください。

---

## 2. お知らせを書く

1. 左のメニューから「お知らせ」を開き、「**追加**」を押す
2. 次の項目を入力する

| 項目 | 書くこと |
| --- | --- |
| タイトル（必須） | 例：第136回冬樟展のお知らせ |
| 内容（必須） | 本文。画像も入れられます（ツールバーの画像ボタン） |
| 概要 | トップや一覧に出る短い紹介文（100字くらい）。空欄なら本文の最初の部分が使われます |
| カテゴリ | 書展・入部・お知らせ・活動 から選ぶ（複数可） |

3. 「公開」を押す

**ポイント**
- 公開した日がお知らせの日付になります。新しいものから順に並びます。
- 画像は大きいままで大丈夫です（サイト側で縮めて表示します）。
- 書展のお知らせなら、あわせて「3. 書展を登録する」もしてください。トップの「次回の書展」は書展のほうから出ます。

---

## 3. 書展を登録する

書展を開くことが決まったら登録します。**会期中・会期前の書展は、トップに「次回の書展」として大きく出ます。**

1. 「書展」を開き、「追加」を押す
2. 次の項目を入力する

| 項目 | 書くこと |
| --- | --- |
| タイトル（必須） | 例：第136回 冬樟展 |
| 開始日・終了日 | 会期の初日と最終日 |
| 会場 | 例：堀川御池ギャラリー |
| 住所 | 例：京都市中京区（区まででOK） |
| 説明 | 時間、入場料、アクセスなど |
| パンフレット画像 | **ポスターの画像**。トップと書展のページに出ます（縦長のポスターでOK） |
| パンフレットURL | パンフレット PDF の Google Drive のリンク（「4. パンフレットを載せる」） |
| 作品アーカイブURL | 作品をまとめたページがあれば、そのリンク |
| 次回の書展 | 基本はチェック不要（下の説明） |

3. 「公開」を押す

**トップに出る書展のきまり**
- 会期が終わっていない書展があれば、それが「**次回の書展**」として出ます。
- 会期が終わると、自動で「**前回の書展**」の表示に変わります。
- 「次回の書展」にチェックを入れると、その書展を優先して出します。うまく出ないときだけ使ってください。使い終わったらチェックを外してください。

---

## 4. パンフレットを載せる

パンフレットは PDF を Google Drive に置いて、そのリンクを書展に貼ります。サイトでは、本のように右から左へめくって読めます。

1. **京大書道部の Google アカウント**の Google Drive を開き、「パンフレット」フォルダに PDF を入れる
   - ファイル名は「136.pdf」のように回数にしておくと、後で探しやすいです
   - 大きすぎると開くのが遅くなります。**20MB 以下**を目安に（印刷用の PDF が大きいときは、画質を下げて書き出してください）
2. PDF を右クリック →「**共有**」→ 一般的なアクセスを「**リンクを知っている全員**」（閲覧者）にする
3. 「**リンクをコピー**」を押す
4. microCMS の書展を開き、「パンフレットURL」に貼り付けて「公開」

**注意**
- 共有を「リンクを知っている全員」にし忘れると、サイトで「読み込めませんでした」と出ます。
- **個人の Google アカウントの Drive に置かないでください。**卒業すると見られなくなります。
- PDF を差し替えた場合、サイトに反映されるまで最大で1週間ほどかかることがあります。すぐ直したいときは、新しいファイルとしてアップロードしてリンクを貼り直してください。

---

## 5. パフォーマンスの記録を載せる

1. 「パフォーマンス」を開き、「追加」を押す
2. 次の項目を入力する

| 項目 | 書くこと |
| --- | --- |
| NFor新歓（必須） | パフォーマンスの種類 |
| 年（必須） | 例：2026 |
| 動画URL（必須） | 写真や動画のリンク（Google フォト、YouTube など） |
| 説明 | 補足があれば |

3. 「公開」を押す

作品紹介ページで、種類ごとに年の新しい順に並びます。

### 種類を増やす（NF・新歓以外）

「NFor新歓」欄の選択肢を増やせば、サイトにその種類の見出しが自動で増えます。

1. 「パフォーマンス」→ 右上の「**API設定**」→「**APIスキーマ**」
2. 「NFor新歓」の項目を開き、選択肢を追加する（例：他大学との合同パフォーマンス）
3. 保存する
4. その種類を選んで記録を登録し、公開する

- 見出しの順番は、選択肢の並び順になります。並べ替えもここでできます。
- 記録が1件もない種類は、サイトには出ません。
- 欄の名前「NFor新歓」は、今後は「種類」に変えておくと分かりやすいです（名前を変えても記録はそのまま残ります）。

### 種類の名前を変える

選択肢の名前を直接書き換えると、もう登録してある記録が古い名前のまま残ることがあります。次の順番でやってください。

1. 新しい名前の選択肢を追加する
2. 古い名前の記録を1件ずつ開き、新しい名前を選び直して公開する
3. 全部付け替えたら、古い選択肢を消す

## 6. サイト設定を変える

練習日や連絡先など、ときどき変わる情報をまとめた1ページです。「サイト設定」を開いて、変えたいところだけ書き換えて「公開」を押してください。

| 項目 | サイトのどこに出るか |
| --- | --- |
| トップの写真 | トップの一番上の写真。**複数入れると5秒ごとに切り替わります**（入れた順）。横長の写真がおすすめ |
| トップの紹介文 | トップの部名の下の文。改行もそのまま出ます |
| 練習日・指導・部室 | 書道部について の表 |
| 部室・部室の説明 / 練習場所・練習場所の説明 | 書道部について の「部室・活動場所」 |
| 入部案内の文章 | 書道部について の「入部案内」 |
| 入部案内の箇条書き | 入部案内の下の箇条書き。**1行に1項目** |
| X のアカウント / Instagram のアカウント | ヘッダーのロゴと、入部案内の連絡先。**@ は付けない**（例：kucc_E201） |
| 連絡先メール | 入部案内の連絡先 |

**空欄にした項目は、元の文章（写真は旧サイトのトップの4枚）が出ます。**消してしまってもページが空になることはありません。

写真をアップロードするときは、画像の「代替テキスト」に何の写真か（例：新歓書道パフォーマンス（2026年））を書いてください。目の見えない人の読み上げや、写真が読み込めないときに使われます。

## 7. 毎年やること

| 時期 | やること |
| --- | --- |
| 4月（新歓の前） | サイト設定の練習日・練習場所・入部案内を確認する。新歓イベントのお知らせを書く |
| 書展が決まったら | 書展を登録し（ポスター画像も）、お知らせを書く |
| 書展のあと | パンフレットを Drive に置いて、書展の「パンフレットURL」に貼る |
| 新歓・NF のパフォーマンスのあと | パフォーマンスの記録を追加する |
| 代替わり | 次の担当に、このマニュアルと部の Google アカウントを引き継ぐ。ドメインの更新時期を確認する |

---

## 8. 困ったとき

**公開したのにサイトが変わらない**
- まず5〜10分待って、ブラウザを再読み込みしてください（スマホは一度タブを閉じてから開き直す）。
- それでも変わらないときは、サイトを作り直す処理（ビルド）が失敗している可能性があります。開発担当に連絡してください。

**パンフレットが「読み込めませんでした」になる**
- Drive の共有が「リンクを知っている全員」になっているか確認してください。
- 貼ったリンクが、Drive の「リンクをコピー」で取ったものか確認してください。

**間違えて消してしまった**
- 記録を消すと元に戻せません。消す前に、本当に要らないか確認してください。
- サイト設定の項目は、空欄にすると元の文章に戻ります。

**ページのデザインを変えたい、新しいページを作りたい**
- 管理画面ではできません。開発担当に相談してください（開発担当向けの説明は、GitHub の README にあります）。
